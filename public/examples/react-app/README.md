# React App Completa

Esta es una aplicación React de ejemplo que demuestra cómo funciona el sistema de preview mejorado.

## Características

- ✅ **Múltiples archivos JSX**: App.jsx y Counter.jsx
- ✅ **Estilos CSS**: App.css con diseño moderno
- ✅ **Hooks de React**: useState para manejo de estado
- ✅ **Componentes reutilizables**: Counter component con props
- ✅ **Interactividad completa**: Botones, inputs, eventos
- ✅ **Diseño responsivo**: CSS Grid y media queries

## Estructura de archivos

```
src/
├── App.jsx          # Componente principal
├── App.css          # Estilos principales
└── components/
    └── Counter.jsx  # Componente contador reutilizable
```

## Cómo funciona

1. **App.jsx**: Componente principal que renderiza la aplicación
2. **Counter.jsx**: Componente reutilizable para contadores
3. **App.css**: Estilos modernos con gradientes y efectos

## Funcionalidades

- **Contadores interactivos**: Dos contadores independientes
- **Input de nombre**: Campo de texto que actualiza el saludo
- **Diseño moderno**: Gradientes, efectos de blur y animaciones
- **Responsive**: Se adapta a diferentes tamaños de pantalla

## Tecnologías utilizadas

- React 18
- Hooks (useState)
- JSX
- CSS3 (Grid, Flexbox, Gradientes)
- Babel (para compilación en tiempo real)

Este proyecto demuestra que el sistema de preview puede manejar aplicaciones React completas con múltiples archivos y componentes.
