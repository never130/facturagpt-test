# 🚀 Proyecto React Básico

## Características

- **📁 Navegación de carpetas**: Explorador tipo acordeón con drag & drop
- **⚛️ Preview en tiempo real**: Ejecuta código React dinámicamente
- **🎨 CSS Modules**: Estilos encapsulados y modulares
- **📱 Responsive**: Diseño adaptativo para móviles

## Estructura del proyecto

```
src/
├── App.jsx                 # Componente principal
├── components/
│   └── ExampleComponent.jsx # Componente de ejemplo
├── styles/
│   └── ExampleComponent.css # Estilos del ejemplo
└── utils/
    └── helpers.js          # Funciones utilitarias
```

## Uso

1. Selecciona un archivo en el explorador
2. Edita el código en el editor
3. Haz clic en "👁️ Preview" para ver el resultado
4. ¡El preview se actualiza automáticamente!

## Tecnologías

- React 18
- CSS Modules
- Babel (para el preview)
- Drag & Drop API
