# ReactApp

Una aplicación React moderna utilizando TypeScript y Tailwind CSS.

## Instalación

1. Clona este repositorio.
2. Navega al directorio del proyecto.
3. Ejecuta `npm install` para instalar las dependencias.

## Ejecución
Ejecuta `npm start` para iniciar la aplicación en modo de desarrollo.

## Construcción
Ejecuta `npm run build` para crear una versión de producción.

## Uso
Navega a `http://localhost:3000` para ver la aplicación en el navegador.
